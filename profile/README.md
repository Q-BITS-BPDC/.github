## What is Q-BITS?

Q-BITS is the quantum computing student community at **BITS Pilani Dubai Campus**. We explore the intersection of quantum mechanics, linear algebra, and computer science — from foundational circuit theory to cutting-edge quantum machine learning and cryptography.

Whether you're a complete beginner curious about what a qubit actually is, or a CS/ECE student looking to build real projects with quantum hardware, Q-BITS is your launchpad.

> *"If you think you understand quantum mechanics, you don't understand quantum mechanics."* — Richard Feynman

## Workshop Tracks

Workshops are tiered by difficulty. Start anywhere that matches your background.

```
Track 0 — Foundations    no prerequisites
Track 1 — Algorithms     linear algebra + Track 0
Track 2 — Applications   Track 1 + basic ML
Track 3 — Hardware       Track 1 + some physics
```

| Track | Workshop | Topics |
|---|---|---|
| 0 | What is a Qubit? | Superposition, Bloch sphere, measurement |
| 0 | Quantum Gates 101 | X, H, CNOT, Toffoli |
| 0 | Your First Circuit | Qiskit basics, Bell states, entanglement |
| 0 | Measurement & Probability | Born rule, expectation values |
| 1 | Deutsch-Jozsa | Quantum parallelism, oracles |
| 1 | Grover's Search | Amplitude amplification |
| 1 | Quantum Fourier Transform | Phase kickback, QFT circuit |
| 1 | Shor's Algorithm | Factoring, period finding |

Full workshop materials → [`workshops`](https://github.com/Q-BITS-BPDC/workshops)

## Resources

A comprehensive reading list across levels. Work through them in order if you're starting from scratch.

### 🟢 Beginner — No prior quantum knowledge needed

| Resource | Format | Notes |
|---|---|---|
| [IBM Quantum Learning](https://learning.quantum.ibm.com/) | Interactive course | Best structured starting point; free |
| [Quantum Country](https://quantum.country/) | Essay + spaced repetition | Covers superposition, entanglement, and basic algorithms |
| [Qiskit Textbook](https://qiskit.org/learn) | Jupyter notebooks | Code-first, runs in browser |
| [Quirk](https://algassert.com/quirk) | Circuit simulator | Drag-and-drop gates, instant intuition builder |
| [Scott Aaronson — Quantum Computing Since Democritus](https://scottaaronson.com/democritus/) | Lecture notes / book | Accessible, witty, conceptually deep |

### 🟡 Intermediate — Linear algebra + basic circuits required

| Resource | Format | Notes |
|---|---|---|
| Nielsen & Chuang — *Quantum Computation and Quantum Information* | Textbook | The standard reference; dense but thorough |
| [MIT OCW 8.370 — Quantum Computation](https://ocw.mit.edu/courses/8-370-quantum-computation-spring-2018/) | Lecture notes + problem sets | Rigorous theoretical treatment |
| [Preskill's Lecture Notes](http://theory.caltech.edu/~preskill/ph229/) | PDF | Caltech Ph229; covers algorithms, error correction, and more |
| [PennyLane Demos](https://pennylane.ai/qml/demonstrations/) | Tutorials | QML-focused; great for variational circuits and QAOA |
| Mermin — *Quantum Computer Science: An Introduction* | Textbook | More accessible than Nielsen & Chuang; good algorithms coverage |

### 🔴 Advanced — Comfortable with quantum algorithms and linear algebra

| Resource | Format | Notes |
|---|---|---|
| [arXiv quant-ph](https://arxiv.org/list/quant-ph/recent) | Preprints | Latest research; filter by cs.ET for quantum computing |
| [Quantum journal](https://quantum-journal.org/) | Open-access journal | Peer-reviewed; high signal-to-noise ratio |
| [Error Correction Zoo](https://errorcorrectionzoo.org/) | Reference | Taxonomy of every known quantum error correcting code |
| Wilde — *Quantum Information Theory* | Textbook | Deep dive into quantum Shannon theory; free on arXiv |
| [Qiskit Patterns](https://docs.quantum.ibm.com/guides) | Docs | Real hardware workflows: transpilation, noise mitigation, Qiskit Runtime |

### 📹 Lectures & Talks

| Resource | Notes |
|---|---|
| [Umesh Vazirani — Quantum Mechanics and Quantum Computation (edX)](https://www.edx.org/course/quantum-mechanics-and-quantum-computation) | Berkeley course; excellent algorithms coverage |
| [John Preskill — Quantum Computing Lecture Series (YouTube)](https://www.youtube.com/playlist?list=PL0ojjrEqIyPy-1RRD8cTD_lF1hflo89Iu) | Caltech Ph219; rigorous and up to date |
| [Anastasia Marchenkova — Quantum Computing (YouTube)](https://www.youtube.com/@AnastasiaMarchenkova) | Approachable explainers for beginners |

### 🔐 Specialised Topics

| Topic | Resource |
|---|---|
| Post-Quantum Cryptography | [NIST PQC Project](https://csrc.nist.gov/projects/post-quantum-cryptography) — the official standardisation process |
| Quantum ML | Schuld & Petruccione — *Machine Learning with Quantum Computers* |
| Quantum Error Correction | Gottesman — [*Stabilizer Codes and Quantum Error Correction*](https://thesis.library.caltech.edu/2900/) (PhD thesis) |
| Near-term (NISQ) Algorithms | Preskill — [Quantum Computing in the NISQ Era and Beyond](https://arxiv.org/abs/1801.00862) |
| Variational Algorithms | Cerezo et al. — [Variational Quantum Algorithms (Nature Reviews Physics)](https://arxiv.org/abs/2012.09265) |
